ULiègeMap αlpha

ULiègeMap est un projet qui vise à aider les étudiants perdus parmi les nombreux locaux de l'ULiège, en utilisant les données ouvertes OpenStreetMap.

Le projet est pour le moment en phase de développement initial. Cela signifie que la majorité des fonctionnalités et des bâtiments/locaux ne sont pas disponibles

Voici l'état d'avancement d'ULiègeMapα :

Fonctionnalités présentes

  • Carte basique des bâtiments étage par étage ;
  • Recherche des bâtiments ;
  • Recherche d'un local par nom ou code (format E/SS, soit Etage/Salle), filtrage par bâtiment ;
  • Géolocalisation

Fonctionnalités à ajouter

  • Détails par local (capacité, prises, etc...) lorsqu'on le cherche/clique dessus ;
  • Accès aux PMR ;
  • Détection de l'étage par géolocalisation (voir faisabilité) ;
  • Ajouter escaliers, ascenseurs et rampes ;
  • Anglais ;
  • ... (Suggestion ?)

Bâtiments

  • Bâtiments présents : B4 (Amphithéâtres de l'Europe) ; B5b (Physique TP) ; B7a (Grands Amphithéâtres) et B7b (Petits Amphithéâtres) ;
  • Bâtiments bientôt disponibles : Complexe du XX Août ; B28 (Montefiore) ; Complexe Pitteurs (I1 ; L3 ; (L5)) ;
  • Liste complète des bâtiments et leurs statuts ;
  • Vous souhaitez nous aider ?

Bugs connus

  • indoor=area n'affiche pas de bordures sur les murs extérieurs ;
  • Pas d'icônes pour les escaliers, ascenseurs, rampes, fontaines et distributeurs ;
  • ...

Nous aider

Pour nous suggérer des fonctionnalités, nous aider en envoyant des plans de bâtiment (préf. en PDF ou DWG) ou nous indiquer des bugs erreurs : ouvrez une "issue" sur GitHub.
